# Домашнее задание

## Условие задачи

Вычислите с использованием цикла `for` значение ряда для заданных пользователем значений $a$ и $n$:

$$a(a + 1) \dots (a + n + 1)$$

## Алгоритм и блок-схема

### Алгоритм

1. Начало.
2. Объявить целочисленные переменные $a$, $n$ и переменную для накопления произведения `prod` типа `long long` со значением $1$.
3. Ввести значения переменных $a$ и $n$ с клавиатуры.
4. Организовать цикл `for` по переменной $i$ от $0$ до $n + 1$ включительно с шагом $1$:
   - Умножить текущее значение `prod` на выражение $(a + i)$.
5. Вывести вычисленное значение `prod`.
6. Конец.

## Реализация программы

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int homework() {
    puts("HOMEWORK-----------------------------------------------------------");
    int a, n;
    long long prod = 1;

    scanf_s("%d %d", &a, &n);

    for (int i = 0; i <= n + 1; i++) {
        prod *= (a + i);
    }

    printf("%lld\n", prod);
    return 0;
}
```

## Результаты работы программы

```text
HOMEWORK-----------------------------------------------------------
2 2
120
```

*Пояснение к тесту:* при $a = 2$, $n = 2$ ряд вычисляется до $a + n + 1 = 2 + 2 + 1 = 5$:
$$2 \times 3 \times 4 \times 5 = 120$$
